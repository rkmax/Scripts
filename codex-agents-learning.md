# Codex Session Learning Pipeline

This workflow snapshots Codex sessions, extracts durable AGENTS.md improvements,
and applies updates only after a preview step.

## Goals

- Avoid analyzing live mutable session files directly.
- Learn only stable operating rules (not tastes or one-off requests).
- Track processed sessions and prevent reprocessing.
- Ignore sessions generated by this automation to avoid feedback loops.
- Require a preview diff before updating `AGENTS.md`.

## Script

`codex-agents-learning.py`

Optional dependency for progress bars:

```bash
pip install tqdm
```

## Data layout

Default processing root: `.codex-agents-learning`

- `state.json`: persistent processing state.
- `runs/<run_id>/sessions/`: copied session snapshots for that run.
- `runs/<run_id>/analysis/`: per-session analysis outputs.
- `runs/<run_id>/consolidation/`: dedup/consolidation outputs.
- `runs/<run_id>/preview/`: AGENTS candidate and diff preview.
- `runs/<run_id>/logs/`: prompts and run diagnostics.

## Commands

List sessions with status:

```bash
python3 codex-agents-learning.py list --limit 100
```

Process newest pending sessions (default 10), generate preview only.
Session analysis runs in parallel with `4` workers by default:

```bash
python3 codex-agents-learning.py run --limit 10
```

If `tqdm` is installed, the run shows progress bars during session analysis.

Override parallelism:

```bash
python3 codex-agents-learning.py run --limit 20 --workers 8
```

Disable progress bars:

```bash
python3 codex-agents-learning.py run --limit 20 --no-progress
```

Print preview diff from latest run:

```bash
python3 codex-agents-learning.py preview
```

Apply candidate AGENTS from latest run:

```bash
python3 codex-agents-learning.py apply
```

## Marker to avoid echo

The script uses this marker in Codex tasks:

`[[CODEX_SESSION_AUTOPROC_V1]]`

Any session containing that marker is ignored by future runs.

## Process details

1. Discover sessions under `~/.codex/sessions/**/*.jsonl`, newest first.
2. Skip already processed sessions (tracked in state).
3. Skip sessions containing the automation marker.
4. Copy selected sessions into a run snapshot directory.
5. Run `codex exec` per session (parallel workers) to produce structured proposals.
6. Mark each successfully analyzed session as processed.
7. Consolidate and deduplicate pending proposals with another `codex exec`.
8. Generate an `AGENTS.md` candidate and unified diff preview.
9. Update `AGENTS.md` only through explicit `apply`.

## Safety behavior

- `run` does **not** modify `AGENTS.md`.
- `apply` verifies `AGENTS.md` hash from preview creation time.
- If AGENTS changed after preview, `apply` aborts unless `--force` is used.
